VoltQA Website — Version 3 (Dark Mode)
This is the final dark-mode version requested after Version 2. It keeps the human, conversational copy while restoring the dark visual identity and original footer structure.

Files
index.html — page content and structure

style.css — dark-mode colors, typography, layout, and responsive design

main.js — mobile-navigation behavior

Before publishing
Replace hello@voltqa.org if your working business email is different.

When you create a Calendly booking page, replace the mailto: button links with your Calendly URL.

Add your LinkedIn URL to the footer after creating the VoltQA LinkedIn page.

Run locally
Open index.html in a browser, or use VS Code with the Live Server extension for automatic reloads while editing.

Publish
Upload index.html, the css folder, and the js folder together to Netlify, Cloudflare Pages, GitHub Pages, Vercel, or regular hosting. Connect voltqa.org in your host's domain settings.

Design
Dark navy-black background

Crisp electric blue and cyan accents, not dusty or earthy tones

Outfit headings and DM Sans body text

No emojis, fake client claims, fake testimonials, or fake data dashboards
